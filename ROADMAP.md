# UniBudget - Roadmap

Plan to complete the app.

## Done
- Firebase Authentication (email + password) with local demo mode
- AuthGate routing and logout
- Dark mode switch
- English translation
- Basic dashboard UI (BudgetSummaryCard, TransactionItem)

## Phase 1 - Authentication
- Configure flutterfire
- Password reset
- Email verification
- User profile

## Phase 2 - Data layer
- Add cloud_firestore
- Extend TransactionModel (income/expense, currency)
- CRUD operations for transactions
- Offline persistence

## Phase 3 - Budgeting features
- Add transaction screen
- Categories management
- Monthly budget and savings goals
- Balance calculations

## Phase 4 - Statistics
- Charts using fl_chart
- Filters by month and category
- Export data

## Phase 5 - History
- Transaction history view
- Search and filter

## Phase 6 - Settings
- Save theme choice in shared_preferences
- Internationalization (i18n)
- Notifications

## Phase 7 - Quality
- State management update
- Testing
- CI setup
- App icon and splash screen
